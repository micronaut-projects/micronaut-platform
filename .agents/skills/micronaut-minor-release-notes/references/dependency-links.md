# Dependency Link Registry

When a release note mentions one of these non-Micronaut transitive or integration dependencies, use the exact Markdown link below. Match the listed aliases case-insensitively. Do not link a dependency that is not mentioned in the release note.

For Spring Boot, apply the version-specific rule before the table: when the released version has major/minor `4.1` (for example, `4.1.0`), link the complete displayed version to the 4.1 release notes: `[Spring Boot 4.1.0](https://github.com/spring-projects/spring-boot/wiki/Spring-Boot-4.1-Release-Notes)`. Do not apply this link to any other Spring Boot major/minor version.
